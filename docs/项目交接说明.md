## 1. 项目当前状态

活动魔方已完成主要业务闭环：

```text
管理员创建负责人
→ 负责人创建活动
→ 管理员审核活动
→ 学生报名
→ 学生签到
→ 学生反馈
→ 负责人查看统计
→ 发放活动成果
```

项目目前处于最终交付整理阶段，不建议继续新增大功能。后续重点应放在演示视频、截图、部署稳定性和答辩材料准备。

## 3. 启动方式

### 后端

1. IDEA 打开 `backend`。
2. 配置 JDK 17。
3. 配置数据库环境变量：

```env
DB_HOST=localhost
DB_PORT=3306
DB_NAME=activity_cube
DB_USER=root
DB_PASSWORD=你的数据库密码
```

4. 运行 `ActivityCubeApplication`。

### 前端

```bash
cd frontend
npm install
npm run dev -- --host 0.0.0.0
```

默认地址：

```text
http://localhost:5173
```

## 4. 数据库初始化方式

全新数据库执行：

```text
sql/activity_cube_final.sql
```

已有数据库升级执行：

```text
docs/sql/*.sql
```

不要在已有重要数据的数据库中执行初始化脚本。

## 6. 主要目录说明

```text
backend/        Spring Boot 后端
frontend/       Vue 3 前端
docs/           文档和 SQL 补丁
sql/            最终初始化 SQL
uploads/        本地上传文件目录，不提交
tmp/            临时文件，不作为正式交付核心内容
```

## 7. 重要配置说明

### backend/src/main/resources/application.yml

- `server.port`：后端端口，默认 8080。
- `spring.datasource.*`：数据库连接，支持环境变量。
- `activity-cube.upload-dir`：上传文件目录。
- `activity-cube.cors-origins`：前端跨域白名单。

### frontend/.env.development

- `VITE_API_BASE_URL`：前端请求后端接口地址。

手机测试时要改成电脑局域网 IP。

## 8. 已知问题

1. 手机浏览器在 HTTP 局域网环境下可能无法调用摄像头，已提供粘贴二维码链接和输入签到码备用方式。
2. 如果电脑换网络，局域网 IP 会变化，需要重新配置前端接口地址并重新生成二维码。
3. `uploads/` 是本地目录，演示时需要保证后端能访问该目录。
4. 如果使用命令行 Maven 报 `mvn not found`，可使用 IDEA Maven 面板或配置 Maven PATH。
