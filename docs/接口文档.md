# 活动魔方接口文档

统一返回格式：

```json
{
  "code": 200,
  "message": "success",
  "data": {}
}
```

认证方式：

- 登录成功后前端保存 token。
- 后续请求携带 `Authorization: Bearer <token>`。
- 未登录返回 401，无权限返回 403 或业务错误提示。

## 1. 登录注册

### POST /api/auth/login

权限：公开。

参数：

- `identifier` 或 `username`：账号、学号或工号。
- `password`：密码。

返回：

- `token`
- `user`
- `role`

常见错误：

- 账号或密码错误。
- 账号已禁用。

### POST /api/auth/register

权限：公开，仅学生注册。

参数：

- `realName`
- `studentNo`
- `password`
- `campus`
- `college`
- `majorName`
- `className`
- `phone`

规则：

- 学号必须为 10 位数字。
- 后端强制 `role=student`。
- 不能通过注册接口创建负责人或管理员。

### GET /api/users/me

权限：登录用户。

作用：获取当前登录用户信息。

## 2. 用户管理

### GET /api/admin/users

权限：管理员。

参数：

- `keyword`
- `role`
- `status`

作用：查询用户列表。

### POST /api/admin/users/organizers

权限：管理员。

作用：创建活动负责人账号。

参数：

- `realName`
- `workNo`
- `password`
- `phone`
- `campus`
- `college`

常见错误：

- 工号已存在。
- 非管理员无权限。

### PUT /api/admin/users/{id}

权限：管理员。

作用：修改用户基础信息。

### PUT /api/admin/users/{id}/status

权限：管理员。

作用：启用或禁用用户。

### PUT /api/admin/users/{id}/reset-password

权限：管理员。

作用：重置用户密码，后端使用 BCrypt 加密保存。

### PUT /api/admin/users/{id}/role

权限：管理员。

作用：修改用户角色。

## 3. 活动管理

### GET /api/activities

权限：登录用户。

参数：

- `keyword`
- `campus`
- `status`

说明：

- 学生端只返回已发布活动。
- 管理员可查看全部活动。
- 负责人查看自己可管理的活动。

### GET /api/activities/{id}

权限：登录用户。

返回：

- `activity`
- `registrationCount`
- `checkinCount`
- `registered`
- `checkedIn`
- `canRegister`
- `canCheckin`
- `canOnlineCheckin`
- `canQrCheckin`

### POST /api/activities

权限：负责人、管理员。

作用：创建活动草稿。

关键参数：

- `title`
- `description`
- `activityMode`
- `checkinMode`
- `activityCategory`
- `campus`
- `location`
- `registerStartTime`
- `registerEndTime`
- `startTime`
- `endTime`
- `checkinStartTime`
- `checkinEndTime`
- `maxParticipants`
- `allowCrossCampus`
- `rewardEnabled`

### PUT /api/activities/{id}

权限：管理员或活动创建者。

作用：编辑活动。

规则：

- 已取消活动不能编辑。
- 负责人只能编辑自己创建的活动。
- 已发布活动修改关键字段会通知报名学生。

### DELETE /api/activities/{id}

权限：管理员或活动创建者。

作用：删除活动。

### POST /api/activities/{id}/cancel

权限：管理员或活动创建者。

作用：取消活动，并通知已报名学生。

### GET /api/activities/admin/reviews

## 5. 报名

### POST /api/activities/{id}/register

权限：学生。

作用：报名活动。

规则：

- 只有报名中活动可报名。
- 同一活动同一学号不能重复报名。
- 人数已满不能报名。

常见错误：

- 当前活动未开始报名。
- 当前活动报名已结束。
- 你已报名，请勿重复提交。
- 该活动人数已满。

### GET /api/activities/{id}/registrations

权限：管理员或活动创建者。

作用：查看报名名单。

### GET /api/my/registrations

权限：学生。

作用：查看我的报名。

### DELETE /api/activities/{id}/registrations/me

权限：学生。

作用：取消自己的报名。

## 6. 签到

### POST /api/activities/{id}/checkin

权限：学生。

参数：

- `code`：签到码，可选。扫码签到必须携带。

规则：

- `checkinMode=online`：允许线上签到。
- `checkinMode=qr`：必须扫码或输入现场签到码。
- `checkinMode=both`：两种方式都支持。
- 未报名不能签到。
- 不能重复签到。
- 必须在签到时间范围内。

常见错误：

- 你尚未报名，不能签到。
- 你已完成签到，请勿重复签到。
- 签到尚未开始。
- 签到已结束。
- 该活动需现场扫码签到。
- 签到二维码无效。

### GET /api/activities/{id}/checkins

权限：管理员或活动创建者。

作用：查看签到名单。

### POST /api/activities/{id}/checkins/manual

权限：管理员或活动创建者。

参数：

- `userId` 或 `studentNo`
- `remark`：补签原因。

作用：人工补签。

### GET /api/activities/{id}/absences

权限：管理员或活动创建者。

作用：查询未签到名单。

### GET /api/my/checkins

权限：学生。

作用：查看我的签到。

## 8. 反馈

### POST /api/activities/{id}/feedback

权限：学生。

参数：

- `feedbackType`：`suggestion`、`issue`、`evaluation`。
- `score`：评分，评价类型必填。
- `content`：反馈内容。
- `suggestion`：改进建议。
- `anonymous`：是否匿名。

规则：

- 活动发布后可提交建议和问题。
- 签到后或活动结束后可提交满意度评价。
- 活动评价必须评分。

### GET /api/activities/{id}/feedbacks

权限：管理员或活动创建者。

作用：查看反馈列表。

### GET /api/activities/{id}/feedback-stats

权限：管理员或活动创建者。

作用：查看反馈统计。

## 14. 文件上传

### POST /api/files/upload

权限：登录用户。

请求方式：`multipart/form-data`

参数：

- `file`

返回：

- `url`
- `fileName`
- `originalName`
- `fileType`
- `size`

### POST /api/files/upload-batch

权限：登录用户。

参数：

- `files`

规则：

- 图片：jpg、jpeg、png、gif、webp，最大 5MB。
- 视频：mp4、webm、mov，最大 100MB。
